# Jeg oppdaterte profilen min med en readme.md fil fra terminalen på pcen.
# -> Brukte først cd 'Onedrive/Skrivebord' (For å komme til skrivebordet på pcen, som forsåvidt er lagret i onedrive)
# -> Så mkdir 'ProfilRepoGitHub' (lager en ny mappe på skrivebordet)
# -> Så touch 'readme.md' (lager en markdown fil med navn readme)
# -> Så gikk jeg hit å redigerte den (altså i visual studio code)
# -> Save markdown filen lokalt på pcen i mappen (ctrl+s)
# -> git status
# -> git add readme.md / kan også bruke git add .
# -> git commit -m 'Første endring i readme filen til profilen' (FOR Å LOGGE ENDRINGEN)
# -> git log (for å dobbeltsjekke :)
# Så lage en repo på github - å kjøre kommandoene: (som står når man lager en repo på github)
# git remote add origin https://github.com/elRobz/elRobz.git
# git branch -M main
# git push -u origin main

# done, oj, må jo lagre endringene å pushe ut igjen! ctrl+s, git status, git add (navn), git commit -m (endring), git push

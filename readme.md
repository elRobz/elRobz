## Jeg oppdaterte profilen min med en readme.md fil fra terminalen på pcen:
1. -> Brukte først cd 'Onedrive/Skrivebord' (For å komme til skrivebordet på pcen, som forsåvidt er lagret i onedrive)
2. -> Så mkdir 'ProfilRepoGitHub' (lager en ny mappe på skrivebordet)
3. -> Så touch 'readme.md' (lager en markdown fil med navn readme)
4. -> Så gikk jeg hit å redigerte den (altså i visual studio code)
5. -> Save markdown filen lokalt på pcen i mappen (ctrl+s)
6. -> git status
7. -> git add readme.md / kan også bruke git add .
8. -> git commit -m 'Første endring i readme filen til profilen' (FOR Å LOGGE ENDRINGEN)
9. -> git log (for å dobbeltsjekke :)
10. Så lage en repo på github - å kjøre kommandoene: (som står når man lager en repo på github)
11. git remote add origin https://github.com/elRobz/elRobz.git
12. git branch -M main
13. git push -u origin main

14. done, oj, må jo lagre endringene å pushe ut igjen! ctrl+s, git status, git add (navn), git commit -m (endring), git push
